# Layout-Generator-Assignment
The objective of this assignment is to design and implement a small program that automatically generates and visualizes multiple building layouts within a fixed rectangular site while respecting a defined set of geometric and spatial rules.

How to Run?
1. Open the layout_generator.py file.
2. Make sure Python is installed and required libraries (matplotlib, shapely) are available.
3. Run the file and enter the number of layouts when prompted.
4. The program generates the layouts, displays each visual layout, and prints information showing whether all rules are satisfied or violated.
